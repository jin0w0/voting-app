# 04: 투표 삭제

Spec: [../spec.md](../spec.md)

**What to build:** 운영자가 `/admin`에서 모든 투표 목록을 최신순으로 보고, 확인 창을 거쳐 투표를 삭제한다. 투표를 삭제하면 그 선택지와 표도 모두 영구 삭제되고, 홈과 관리 목록에서 바로 사라진다. 삭제된 투표 링크는 "존재하지 않는 투표입니다" 안내로 이어진다.

**Blocked by:** 02 (투표 만들기와 목록)

**Status:** done

- [x] `/admin`에 투표 목록(최신순)을 보여주고, 각 항목에 삭제 버튼을 둔다
- [x] 삭제 전에 확인 창을 띄우고, 취소하면 아무 일도 일어나지 않는다
- [x] 투표 삭제 서버 액션은 액션 안에서 직접 운영자 세션을 검증한다. 세션이 없으면 거부한다
- [x] 삭제하면 선택지와 표가 DB cascade로 함께 사라진다(03이 먼저 들어왔다면 표까지 포함)
- [x] 삭제 후 홈과 `/admin` 목록에 곧바로 반영된다
- [x] 삭제된 투표의 `/polls/[id]`는 없는 투표로 처리된다
