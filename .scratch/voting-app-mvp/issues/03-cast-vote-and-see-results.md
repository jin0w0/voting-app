# 03: 투표하기와 결과

Spec: [../spec.md](../spec.md)

**What to build:** 투표자(Voter)가 `/polls/[id]`에서 선택지 하나를 골라 제출하면 표(Vote)가 기록되고 바로 결과(Results)가 보인다. 결과에는 선택지별 표 수, 백분율, 가로 막대, 총 표 수, 내가 고른 선택지 표시가 들어간다. 같은 브라우저로 다시 들어오면 투표 폼 대신 결과가 보인다. 투표하지 않은 투표자에게는 결과 데이터를 보내지 않는다. 없는 투표 링크는 "존재하지 않는 투표입니다"(404)로 안내한다. 홈 목록에 각 투표의 총 표 수를 표시한다.

**Blocked by:** 02 (투표 만들기와 목록)

**Status:** ready-for-agent

- [ ] 스키마: `votes`(id, poll id cascade, option id cascade, 투표자 ID, 생성 시각)와 (poll id, 투표자 ID) 유일 제약. 마이그레이션을 생성해 커밋하고 적용한다
- [ ] 투표자 쿠키: 처음 투표할 때 무작위 익명 ID를 발급한다. httpOnly, 1년, 서명하지 않음(ADR-0001)
- [ ] 투표하기 서버 액션: 선택지를 골랐는지, 그 선택지가 해당 투표에 속하는지 확인하고 표를 기록한다. 유일 제약 위반(중복 제출이나 동시 제출)은 "이미 투표함"으로 처리하고 결과를 보여준다
- [ ] 제출 사이에 투표가 삭제되었으면 "존재하지 않는 투표입니다"를 보여준다. 그 밖의 제출 실패는 다시 시도할 수 있게 오류를 보여준다
- [ ] 선택지를 고르지 않으면 제출할 수 없다
- [ ] 투표 규칙 모듈의 결과 계산: 선택지별 표 수(순서 유지)를 받아 표 수, 반올림한 백분율, 총 표 수를 돌려준다. 총 0표면 모두 0%이다
- [ ] 테스트: 총 0표, 한 선택지만 표를 받은 경우, 1/3처럼 반올림이 필요한 경우
- [ ] `/polls/[id]`는 서버에서 판단한다. 기존 표가 있으면 결과를, 없으면 투표 폼을 보여준다. 새로고침하면 최신 결과가 보인다
- [ ] 없는 id나 삭제된 id는 404 안내 페이지로 보낸다
- [ ] 홈 목록에 각 투표의 총 표 수를 표시한다
- [ ] 여러 투표에 각각 한 표씩 던질 수 있다
