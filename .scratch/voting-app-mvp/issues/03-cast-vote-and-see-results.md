# 03: 투표하기와 결과

Spec: [../spec.md](../spec.md)

**What to build:** 투표자(Voter)가 `/polls/[id]`에서 선택지 하나를 골라 제출하면 표(Vote)가 기록되고 바로 결과(Results)가 보인다. 결과에는 선택지별 표 수, 백분율, 가로 막대, 총 표 수, 내가 고른 선택지 표시가 들어간다. 같은 브라우저로 다시 들어오면 투표 폼 대신 결과가 보인다. 투표하지 않은 투표자에게는 결과 데이터를 보내지 않는다. 없는 투표 링크는 "존재하지 않는 투표입니다"(404)로 안내한다. 홈 목록에 각 투표의 총 표 수를 표시한다.

**Blocked by:** 02 (투표 만들기와 목록)

**Status:** done

- [x] 스키마: `votes`(id, poll id cascade, option id cascade, 투표자 ID, 생성 시각)와 (poll id, 투표자 ID) 유일 제약. 마이그레이션을 생성해 커밋하고 적용한다
- [x] 투표자 쿠키: 처음 투표가 기록될 때 무작위 익명 ID를 발급한다. httpOnly, 1년, 서명하지 않음(ADR-0001)
- [x] 투표하기 서버 액션: 선택지를 골랐는지, 그 선택지가 해당 투표에 속하는지 확인하고 표를 기록한다. 유일 제약 위반(중복 제출이나 동시 제출)은 "이미 투표함"으로 처리하고 결과를 보여준다
- [x] 제출 사이에 투표가 삭제되었으면 "존재하지 않는 투표입니다"를 보여준다. 그 밖의 제출 실패는 다시 시도할 수 있게 오류를 보여준다
- [x] 선택지를 고르지 않으면 제출할 수 없다
- [x] 투표 규칙 모듈의 결과 계산: 선택지별 표 수(순서 유지)를 받아 표 수, 반올림한 백분율, 총 표 수를 돌려준다. 총 0표면 모두 0%이다
- [x] 테스트: 총 0표, 한 선택지만 표를 받은 경우, 1/3처럼 반올림이 필요한 경우
- [x] `/polls/[id]`는 서버에서 판단한다. 기존 표가 있으면 결과를, 없으면 투표 폼을 보여준다. 새로고침하면 최신 결과가 보인다
- [x] 없는 id나 삭제된 id는 404 안내 페이지로 보낸다
- [x] 홈 목록에 각 투표의 총 표 수를 표시한다
- [x] 여러 투표에 각각 한 표씩 던질 수 있다

## Comments

- 2026-09-28 구현 완료. 결과 계산 테스트 3개를 추가해 전체 31개가 통과함. `votes` 마이그레이션을 Neon에 적용함. `next start`로 다음을 확인하고 시험 데이터는 삭제함: 투표 폼, 투표 전에는 결과가 보이지 않음, 선택하지 않은 제출, 다른 투표의 선택지, 첫 투표 때 쿠키 발급, 결과(표 수·백분율·막대·내 선택), 동시 3회 제출이 1표로 기록됨, 다시 투표해도 무시됨, 투표별 한 표, 홈의 총 표 수, 404, 화면을 연 뒤 투표가 삭제된 경우.
- 리뷰 반영: 쿠키는 표가 실제로 기록됐을 때만 발급함. 형식이 잘못된 `voter_id` 쿠키는 무시하고 새로 발급함(전에는 그 브라우저가 영원히 투표할 수 없었음). 네트워크 실패는 `error.tsx`에서 다시 시도할 수 있게 함.
- 참고: 404 안내 문구는 HTML 본문이 아니라 RSC 페이로드로 전달되고 브라우저가 렌더링함(상태 코드는 404). JS 없이 삭제된 투표에 제출하면 404 안내 페이지가 나옴.
