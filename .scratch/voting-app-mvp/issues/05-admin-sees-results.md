# 05: 운영자 결과 보기

Spec: [../spec.md](../spec.md)

**What to build:** 운영자는 투표하지 않았어도 `/admin`에서 각 투표의 결과(선택지별 표 수, 백분율, 막대, 총 표 수)를 볼 수 있다. 일반 투표자에게 적용되는 "투표한 뒤에만 결과 공개" 규칙은 운영자 화면에는 적용되지 않는다. 운영자가 `/polls/[id]`에 들어가면 일반 투표자와 똑같이 취급한다.

**Blocked by:** 03 (투표하기와 결과)

**Status:** ready-for-agent

- [ ] `/admin` 목록의 각 투표에서 결과를 볼 수 있다(펼치기나 별도 보기 중 편한 방식)
- [ ] 결과 표시는 03의 결과 계산과 결과 화면을 다시 사용한다
- [ ] 결과 조회는 유효한 운영자 세션이 있을 때만 된다
- [ ] 운영자가 `/polls/[id]`에서 투표하는 흐름은 일반 투표자와 같다(특별 취급하지 않음)
