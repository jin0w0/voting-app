# 03: 목록의 마감 표시와 정렬

Spec: [../spec.md](../spec.md)

**What to build:** 홈과 운영자 목록에서, 마감 시각이 있는 진행 중인 투표에는 "10월 1일 18:00 마감"이, 마감된 투표에는 "마감됨" 배지가 보인다. 진행 중인 투표가 먼저 나오고, 각 묶음 안에서는 최신순이다. 마감 시각이 지나면 새로고침했을 때 "마감됨"으로 바뀐다.

**Blocked by:** 02 (마감 시각 설정과 자동 마감)

**Status:** done

- [x] 목록 조회가 마감 시각과 DB 현재 시각을 읽고, 투표 규칙 모듈의 판정으로 상태를 정한다
- [x] 정렬: 진행 중 먼저, 그다음 마감됨. 각 묶음 안은 최신순
- [x] 홈 목록: 진행 중이면서 마감 시각이 있으면 "… 마감", 마감됐으면 "마감됨" 배지. 마감 시각이 없으면 표시 없음. 총 표 수는 그대로
- [x] 운영자 목록: 같은 표시와 정렬. 결과 보기와 삭제는 그대로
