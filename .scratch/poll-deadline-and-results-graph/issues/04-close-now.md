# 04: 지금 마감

Spec: [../spec.md](../spec.md)

**What to build:** 운영자가 운영자 목록에서 진행 중인 투표를 "지금 마감" 버튼으로 앞당겨 마감한다. 누르기 전에 "마감하면 다시 열 수 없습니다" 확인 창이 뜬다. 마감 시각이 있든 없든 똑같이 동작하고, 마감된 투표에는 버튼이 보이지 않는다. 마감된 투표는 다시 열리지 않는다.

**Blocked by:** 02 (마감 시각 설정과 자동 마감)

**Status:** done

- [x] 스키마: `polls`에 앞당긴 마감 시각 열(시간대 있음, 비어 있을 수 있음)을 추가하고 마이그레이션을 생성·커밋·적용한다
- [x] 투표 규칙 모듈의 상태 판정에 앞당긴 마감 시각을 더한다(있으면 마감 시각과 관계없이 마감됨). 테스트를 추가한다
- [x] 앞당겨 마감: 앞당긴 마감 시각이 비어 있을 때만 DB 현재 시각으로 채운다. 이미 마감된 투표는 바꾸지 않는다
- [x] "지금 마감" 서버 액션은 액션 안에서 운영자 세션을 검증하고, 마감한 뒤 `/admin`으로 돌아간다
- [x] 운영자 목록: 진행 중인 투표에만 버튼을 두고, 확인 창을 띄운다. 마감한 투표도 삭제할 수 있다
- [x] 앞당겨 마감한 투표는 표를 받지 않고, 누구나 결과를 보며, 목록에 "마감됨"으로 표시된다(02·03의 판정을 그대로 씀)

## Comments

- 2026-09-28 완료(03보다 먼저 해서 목록 판정이 처음부터 앞당긴 마감을 포함함). 실제 DB로 확인: 버튼은 진행 중인 투표에만 있음, 운영자 세션 없으면 거부, 마감하면 `closed_at` 기록, 다시 눌러도 처음 시각 유지, 마감 시각이 지나 저절로 마감된 투표는 바꾸지 않음, 마감한 투표도 삭제 가능. 삭제 버튼과 확인 창 버튼을 하나의 공통 컴포넌트로 합침. 확인 창 취소는 브라우저로 직접 확인하지 못함.
