# 02: 마감 시각 설정과 자동 마감

Spec: [../spec.md](../spec.md)

**What to build:** 운영자(Admin)가 투표를 만들 때 마감 시각(Deadline)을 선택적으로 정한다(한국 시간, 분 단위, 지금보다 뒤, 기본은 "마감 시각 없음"). 진행 중(Open)인 투표 페이지에는 "10월 1일 18:00 마감 (한국 시간)"이 보인다. 마감 시각이 지나면 투표는 마감됨(Closed)이 되어 표를 받지 않고, 투표 페이지는 "마감되었습니다"와 결과를 **누구에게나** 보여준다(투표했다면 "내 선택"도 표시). 마감 판정은 DB 현재 시각으로 한다.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 데이터 정리: 시작할 때 DB의 투표 수를 셈 → 0개라 지울 것이 없었음
- [x] 스키마: `polls`에 마감 시각 열(시간대 있음, 비어 있을 수 있음)을 추가하고 마이그레이션을 생성·커밋·적용한다
- [x] 투표 규칙 모듈의 입력 검증이 마감 시각 입력(없음 또는 "YYYY-MM-DDTHH:mm")과 현재 시각을 받는다. 한국 시간(UTC+9)으로 해석하고, 형식 오류는 "마감 시각을 다시 입력하세요.", 지금이거나 지난 시각은 "마감 시각은 지금보다 뒤여야 합니다."로 거부한다
- [x] 투표 규칙 모듈에 투표 상태 판정(마감 시각, 현재 시각 → 진행 중/마감됨)을 추가한다. 앞당긴 마감 인자는 04에서 더한다
- [x] 테스트: 마감 시각 없음 통과, 한국 시간 해석, 1분 뒤 통과, 정각·지난 시각 거부, 형식 오류 거부, 다른 필드 오류와 함께 보고. 판정: 마감 시각 없음은 진행 중, 1분 전은 진행 중, 정각과 그 뒤는 마감됨
- [x] 만들기 폼: "마감 시각 정하기" 체크박스와 날짜·시각 입력, "(한국 시간)" 안내. 실패하면 마감 시각 입력도 다시 채운다
- [x] 투표 조회가 마감 시각과 DB 현재 시각을 함께 읽어 판정한다
- [x] 표 기록: 마감된 투표면 기록하지 않고 쿠키도 발급하지 않는다. 투표 페이지는 마감 안내와 결과를 보여준다
- [x] 투표 페이지: 진행 중이면 마감 시각을 표시(있을 때만), 마감되면 "마감되었습니다" + 결과, 투표 폼 없음. 카운트다운 없음
- [x] 마감 시각 표시 형식: 한국 시간 "10월 1일 18:00", 올해가 아니면 연도를 붙인다

## Comments

- 2026-09-28 완료. 검증·판정 테스트를 추가했고, 리뷰에서 나온 있을 수 없는 날짜(2월 30일, 24:00) 거부 테스트도 더함. 실제 DB로 확인: 마감 시각 저장(한국 시간), 투표 페이지 표시, 마감 뒤 제출은 표 기록 없음·쿠키 없음, 마감 후 누구나 결과, 1위 표시. 마감 시각 입력은 CSS로만 보이고 숨겨서 JavaScript 없이도 입력할 수 있음.
- 마감 뒤 제출하면 투표 페이지로 돌아가 "마감되었습니다" 배지와 결과를 보여줌. 폼 안의 "이 투표는 마감되었습니다" 문구는 스펙상 선택 사항이라 넣지 않음.
