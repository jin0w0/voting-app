# 01: 결과 그래프 다듬기와 1위 강조

Spec: [../spec.md](../spec.md)

**What to build:** 결과(Results) 화면의 막대가 두껍고 읽기 쉬워지고, 가장 많은 표를 받은 선택지(동점이면 모두)가 진한 색과 "1위" 표시로 강조된다. 모두 0표면 1위 표시는 없다. "내 선택" 표시는 1위 강조와 구분되게 유지한다. 투표 페이지와 운영자 목록이 같은 결과 컴포넌트를 쓰므로 두 화면 모두 바뀐다.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 투표 규칙 모듈의 결과 계산이 선택지마다 1위 여부를 돌려준다(동점이면 모두 1위, 총 0표면 1위 없음)
- [x] 테스트: 한 선택지가 1위, 동점 1위, 총 0표. 기존 백분율 테스트는 그대로 통과
- [x] 막대를 더 두껍게 하고 선택지 이름과 "N표 · N%"를 막대와 함께 읽히게 배치한다. 긴 선택지 이름은 줄바꿈한다
- [x] 한 가지 색 계열에서 1위만 진한 색과 "1위" 표시로 강조한다. 차트 라이브러리는 쓰지 않는다
- [x] "내 선택" 표시를 유지하고 1위 강조와 구분되게 한다
- [x] 라이트·다크 모드 모두에서 대비를 확인한다

## Comments

- 2026-09-28 완료. 1위 테스트 3개(한 선택지, 동점, 0표). 이름과 숫자는 막대 위에 두고(막대가 반쯤 찬 곳에서 글자 대비가 깨지지 않게), 막대 색은 배경 대비 3:1 이상이 되도록 계산해 정함: 라이트는 1위 indigo-800, 나머지 indigo-500, 다크는 1위 indigo-200, 나머지 indigo-500. 실제 다크 모드 화면은 브라우저로 직접 확인하지 못함.
